# Game chrome layout

See `.cursor/rules/game-chrome-layout.mdc`.

- Centered column inside the **390px** mobile shell. Wheel must not resize it.
- Wheel diameter = **75%** of grid (not 55% — too small).
- Peek ≈ **20–25%** of diameter (full ideal peek — do not clamp to a tiny gap).
- Wheel: `fixed; right: 0`.
